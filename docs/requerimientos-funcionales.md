# Requerimientos funcionales

1. Consultar alojamientos disponibles.
2. Filtrar por ciudad, huéspedes, tipo y precio máximo.
3. Consultar el detalle de un alojamiento.
4. Seleccionar fechas y huéspedes.
5. Calcular cotización.
6. Registrar reserva simulada.
7. Consultar mis reservas.
8. Mostrar mensajes de error y estados sin información.
